# Operating System Lab Programs

This repository contains implementations of common Operating System lab problems. The programs are organized by topic and implemented using C and Python.

## Folder Structure

```
OS-Lab-Programs/
│
|-- Process/          # C Programs
|-- Scheduling/       # Python Programs
|-- Deadlock/         # Python Programs
|-- Memory/           # Python Programs
```

## Process (C)

* Q1: Process creation using fork()
* Q2: Parent and child execution (printing numbers)
* Q3: Creating multiple child processes and displaying process tree

## CPU Scheduling (Python)

* Q4: First Come First Serve (FCFS)
* Q5: Shortest Job First (Non-Preemptive)
* Q6: Shortest Remaining Time First (SRTF)
* Q7: Round Robin Scheduling
* Q8: Priority Scheduling

## Deadlock (Python)

* Q9: Banker’s Algorithm (Deadlock Avoidance)
* Q10: Deadlock Detection Algorithm

## Memory Management (Python)

* Q11: FIFO Page Replacement
* Q12: LRU Page Replacement

## How to Run

### Compile and Run C Programs

```
gcc filename.c -o output
./output
```

### Run Python Programs

```
python3 filename.py
```
